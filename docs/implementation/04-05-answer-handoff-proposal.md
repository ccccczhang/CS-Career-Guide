### 4. 重复键与模型失败后怎么重试？

**请确认：** 同键同输入、同键不同输入、失败后同键、新键分别怎么处理？是否允许重试失败回答，如何表达用户明确重试？

**建议：**

- 相同键、相同输入：复用原记录；成功后不重新调用模型。
- 相同键、不同 question_id 或 answer：409，不覆盖原回答。
- 相同键仍生成中：返回明确的处理中状态或冲突，不再次调用模型；HTTP状态及客户端行为待定。
- 模型失败：保存 failed 与安全 failure_code，保留原回答。
- 失败重试不应直接换 request_id，否则会新增一条回答。需要确定同键是否重试，或引入显式重试操作/字段；如扩展 HTTP，请先走公共契约审核。
